# Public MCP host catalog

The first two lines of `catalog.tsv` record the official registry source, collection date in UTC, page count and number of server records processed. Each subsequent row contains one exact hostname and a registry publisher/server ID. The signed release embeds this snapshot. New or removed registry entries take effect after a maintainer refreshes the snapshot and ships a new build.

Run `python3 internal/mcpdns/tools/refresh_catalog.py` from the checkout to refresh. The script traverses the official HTTPS bulk listing with `limit=100` and `version=latest` through its final cursor. It needs no client config or credentials. A failed or incomplete traversal leaves the previous snapshot in place. For a fixed set of registry records the host selection, publisher tie-break and order are deterministic. The registry may change during pagination.

Only active latest entries with a literal HTTPS remote using streamable HTTP or SSE are considered. The host must have an exact `mcp` subdomain label and belong to the publisher’s reverse-DNS namespace, or match a separately reviewed dedicated publisher/host pair in the refresh script. The filter rejects URL templates, IP addresses, wildcards, userinfo, nonstandard ports, reserved local/example names and shared API domains that lack a dedicated MCP label. Registry publication establishes public documentation of the endpoint. Runtime decisions still require a locally configured host, network exclusions, two consecutive native failures and certificate-validated alternate TLS.

The Go worker embeds the TSV. The macOS build embeds the host column of that same TSV into the privileged helper using packaging/helper/catalog_source.py. Run `python3 packaging/helper/test_dns_lease.py` on macOS to exercise the helper’s lease policy. Run `go test ./internal/mcpdns` and `python3 -B -m unittest discover -s internal/mcpdns/tools` to check the runtime and generator policies. Refresh and review the host diff when updating a release that needs newer MCP endpoint coverage.
