AI Exit Guard 1.12.0

Откройте AI Exit Guard.pkg внутри образа DMG. Подтвердите установку, затем запустите AI Exit Guard из «Программ». Щит в строке меню показывает общую оценку. При обновлении он сохраняет последнюю свежую оценку. Новое предупреждение показывается сразу, улучшение — после окончания проверки. Нажмите его, чтобы увидеть рекомендацию. Выберите Claude или ChatGPT для пояснения. Адреса и баллы находятся в «Технических сведениях».

Зелёный — «Риска не обнаружено». Все четыре домена подтвердили IP и поддерживаемую страну, у всех адресов низкий общий риск IP123. Когда IP123 видит тот же выход, приложение также проверяет доверие к адресу для конкретного ИИ. Если IP123 оценил другой выход для ИИ, Guard показывает жёлтый статус.

Жёлтый — «Есть замечания». Прочитайте одну строку под итогом. Поводом может быть средняя оценка, смена адреса между проверками или недостаток свежих данных. При недоступной сети, системном прокси или PAC приложение не может подтвердить выход.

Красный — «Нельзя пользоваться». У хотя бы одного маршрута высокий риск либо сервис не поддерживает страну, указанную доменом. Откройте карточку сервиса, чтобы увидеть, касается ли это сайта или API.

Приложение проверяет claude.ai, api.anthropic.com, chatgpt.com и api.openai.com при подключении, после сна и каждые две минуты. Срок действия результата — три минуты. Изменение сети сбрасывает результаты сразу после обнаружения. При повторной проверке зелёный итог появляется после свежих ответов всех четырёх маршрутов. Предыдущая свежая красная оценка действует до нового результата. Кнопка «Проверить» запускает проверку вручную.

Откуда берётся оценка

• Guard читает IP и страну из HTTPS-ответа самого домена. При настроенном прокси диагностика идёт через него. Это проверка маршрута диагностического запроса. Маршрут браузера или клиента ИИ может отличаться при правилах VPN по приложениям.
• IP123 оценивает репутацию конкретного IP. До 33 включительно — низкий риск, свыше 66 — высокий. Для оценки доверия ИИ адрес домена должен совпасть с адресом соединения с IP123. На шкале доверия низкие значения хуже. Красная оценка любого из этих источников имеет приоритет.
• IPinfo получает только адрес, возвращённый конкретным доменом, и показывает справку в подробностях. Расхождение стран у домена и IPinfo даёт жёлтую оценку.
• Списки доступных стран сверены 22 ноября 2026 года. Для Украины есть региональные исключения, поэтому одной страны недостаточно. Через 90 дней приложение сообщает, что списки нужно обновить. Источники:
  Anthropic — https://www.anthropic.com/legal/supported-regions
  OpenAI — https://help.openai.com/en/articles/7947663-chatgpt-and-openai-api-supported-countries-and-territories

В настройках можно включить уведомления о красной оценке и запуск при входе в macOS. Для диагностики достаточно обычной учётной записи macOS. Приложение работает без аккаунта, не читает чаты и хранит историю IP локально до 30 дней.

Оценка относится к проверенному выходному IP на момент проверки. Решение по аккаунту принимает сам сервис. Guard предупреждает о риске. Вы можете отдельно включить маршрут через выбранный прокси.

История IP открывается из карточки сервиса. История хранится на этом Mac до 30 дней для каждого домена отдельно. Две смены IP за 15 минут включают красное предупреждение для адресов без прежней зелёной оценки. Ранее разрешённый адрес всё равно проходит текущие проверки. Это выбранный порог приложения. Anthropic не указала числовой порог в справке о проверках личности: https://support.claude.com/en/articles/14328960-identity-verification-on-claude

После смены на незнакомый адрес Guard ждёт подтверждения его стабильности повторным измерением спустя две минуты. Возврат на ранее разрешённый адрес проходит обычную проверку. Во время обновления отображается последняя свежая оценка.

Прокси для Claude и ChatGPT

На главном экране откройте блок «Прокси». Выберите протокол из кабинета провайдера. Вставьте логин:пароль@сервер:порт, сервер:порт:логин:пароль или полный URL прокси, затем нажмите «Подключить». Guard трижды проверит выход четырёх доменов и предложит macOS применить настройки сети. Пароль хранится в Связке ключей. Для замены сначала нажмите «Отключить прокси».

Системное правило направляет HTTPS по основным доменам Claude и OpenAI через локальный клиент Guard, затем через выбранный прокси. Остальные сайты идут обычным маршрутом. Изменение действует на новые соединения браузеров и приложений с поддержкой системного PAC. После подключения перезапустите открытый клиент. Для CLI используйте кнопки Claude Code или Codex в этом окне. Отдельные прокси в приложениях, сторонние провайдеры и голосовой UDP-трафик имеют другие маршруты. Это выборочный прокси, а не системная блокировка.

Если Happ перехватывает системный маршрут, панель показывает «через Guard». Используйте кнопки «Открыть Claude» и «Открыть ChatGPT» или кнопки CLI. Окна Guard используют отдельный профиль Chrome или Edge; при первом открытии потребуется вход. Обычные окна, нативные приложения и ранее запущенные CLI под управлением такого VPN могут выходить с другого IP.

При активном Happ Guard может попросить macOS разрешить применение правила к туннелю. Надпись «Прокси проверен» относится к выходу через Guard. Фактические подключения приложений видны в разделе подключений.

«Подключения приложений» показывает открытые TCP-соединения текущего пользователя. У соединений через Guard указан домен принятого прокси-туннеля. Внешние соединения сравниваются с текущими IP четырёх проверяемых доменов, поэтому возможны совпадения на общем сервере. Короткое соединение между обновлениями может не попасть в список.

Килл-свитч
Переключатель на главной панели управляет запретом прямого подключения к основным адресам Claude и OpenAI. Откройте AI Exit Guard.pkg из образа DMG и один раз подтвердите установку системного помощника. Затем переключатель работает без пароля администратора. После обновления Guard всегда используйте установщик той же версии. Правило сохраняется после выхода из Guard и перезагрузки Mac. Чтобы снять его, выключите переключатель до удаления приложения. Снятие запрета сохраняет выбранный прокси.
Guard отправляет доменное имя внешнему прокси. При обрыве туннеля запрос завершается ошибкой. Программы, которые пытаются подключиться напрямую через системный DNS, для перечисленных адресов получат адрес этого Mac. Остальные имена сохраняют обычный маршрут. Приложения со своим DNS, уже открытые прямые соединения, обращения по IP и другие имена находятся вне действия этого правила. Для Claude Code и Codex используйте настроенный провайдер T3 либо команды из меню Guard.

Доступ через встроенный прокси
При запуске доступ закрыт до проверки маршрута сервиса. Красный результат закрывает действующие туннели и новые подключения. Guard проверяет прокси отдельно и возобновляет доступ после полного зелёного результата. Разрешение действует до трёх минут со времени самой ранней проверки. Повторная проверка начинается каждые две минуты. Прокси может сменить выход между проверками. Проверяется выход Guard; приложение со своим сетевым маршрутом требует отдельной проверки. Переключатель системного DNS дополнительно закрывает прямой выход к перечисленным в правиле именам.

Google Antigravity
После проверки прокси нажмите «Открыть Antigravity» в строке Antigravity. Если приложение уже открыто, завершите его через ⌘Q. Этот запуск использует Guard для окна и языкового сервера. При красной оценке активные туннели закрываются. Guard проверяет страну анонимной страницы входа Google. Google отдельно проверяет доступность своего сервиса для аккаунта и региона.

Общий или индивидуальный прокси
Выберите сервис в главном окне. Нажмите «Индивидуальный», вставьте строку прокси, укажите протокол и нажмите «Проверить и применить». Для возврата выберите «Общий». При отказе своего прокси соединения сервиса ждут восстановления выбранного маршрута.

Защита известных доменов работает через локальный HTTPS-вход при включённом килл-свитче. Настройки → «Защитить процессы T3» включает строгий запуск новых CLI-процессов. «Системные правила» включает или выключает автозапуск дополнительного фильтра ProxyBridge.
