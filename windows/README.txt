AI Exit Guard для Windows x64

Распакуйте ZIP в постоянную папку, запустите AI Exit Guard.exe и выберите «Подключить прокси». Вставьте адрес, например socks5://логин:пароль@сервер:порт. Оставьте поле IP пустым, и Guard определит адрес выхода при подключении. Подтвердите системный запрос Windows, чтобы известные домены ИИ использовали этот маршрут. Пароль сохраняется локально с защитой Windows DPAPI.

«Только прокси» включён при первом запуске. В этом режиме проверка IP не обрывает соединения. Чтобы проверять риск перед доступом, отключите этот режим в настройках перед подключением. При проблеме с одним сервисом нажмите его название на главной. В разделе «Отдельные прокси» можно задать свой выход для каждого сервиса.

Правило использует системный DNS для известных имён ИИ. Приложения с собственным DNS, прямыми адресами или другими туннелями могут выбрать другой путь. Обычные адреса Git, SSH и MCP используют свои сетевые настройки.

Крестик сворачивает Guard в область уведомлений. «Отключить прокси» снимает созданный при подключении системный маршрут. Windows может запросить подтверждение. Перед удалением программы отключите прокси. Если в прошлой версии вы включали защиту доменов вручную, снимите прежнее правило в настройках.
