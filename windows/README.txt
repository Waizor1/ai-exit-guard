AI Exit Guard для Windows x64

Распакуйте ZIP в постоянную папку, запустите AI Exit Guard.exe и выберите «Подключить прокси». Выберите HTTP, HTTPS или SOCKS5, нажмите «Вставить», затем «Подключить». Поддерживаются логин:пароль@сервер:порт и сервер:порт:логин:пароль. Если в строке указан протокол, Guard выберет его автоматически. Адрес выхода Guard определяет сам. Подтвердите системный запрос Windows, чтобы известные домены ИИ использовали этот маршрут. Пароль сохраняется локально с защитой Windows DPAPI.

По умолчанию Guard работает в режиме «Только прокси». Нажмите «Проверить адрес», чтобы увидеть оценку и короткую причину прямо под названием сервиса. Для автоматической блокировки включите «Защита по IP» на главном экране. Переключение режима переподключает прокси. Рабочие инструменты используют обычную сеть, а вызовы известных адресов ИИ через Guard зависят от режима защиты.

Правило использует системный DNS для известных имён ИИ. Приложения с собственным DNS, прямыми адресами или другими туннелями могут выбрать другой путь. Обычные адреса Git, SSH и MCP используют свои сетевые настройки.

Крестик сворачивает Guard в область уведомлений. «Отключить прокси» снимает созданный при подключении системный маршрут. Windows может запросить подтверждение. Перед удалением программы отключите прокси. Если в прошлой версии вы включали защиту доменов вручную, снимите прежнее правило в настройках.

«Активные подключения» на главном экране и в меню трея показывает активные туннели и последние 64 завершения, ошибки или блокировки в текущем сеансе Guard. Возможный обход определяется по совпадению адреса активного TCP-соединения на порту 443 с локальным кэшем DNS. Общий IP, собственный DNS приложения и UDP ограничивают точность этой проверки. Новую строку прокси видно при вводе. Снимите «Показывать строку», чтобы скрыть её; при следующем запуске сохранённые данные скрыты.

Если провайдер выдал три значения отдельно, включите «Ввести по полям» и вставьте адрес с портом, логин и пароль в свои поля. Для прокси без авторизации оставьте логин и пароль пустыми.
