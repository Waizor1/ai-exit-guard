AI Exit Guard — Windows x64, предварительная версия

Распакуйте ZIP в постоянную папку и откройте AI Exit Guard.exe. Введите общий прокси в формате http://логин:пароль@сервер:порт или socks5://логин:пароль@сервер:порт. Укажите фактический выходной IP, который вы хотите закрепить. При необходимости заполните отдельную строку Claude, ChatGPT или Antigravity. Секреты сохраняются с защитой Windows DPAPI для вашего пользователя.

«Подключить» запускает локальный прокси 127.0.0.1:39178. У каждого сервиса своя проверка репутации, страны и ожидаемого адреса. При красном статусе или истечении срока проверки его соединения через Guard закрываются. Приложения с настройкой HTTP-прокси можно подключить к этому адресу сразу.

«Системные правила» использует отдельно устанавливаемый ProxyBridge 4.3.0. После установки закройте окно ProxyBridge и нажмите кнопку снова. Разрешите запуск сетевого фильтра. Пока открыто его окно командной строки, действуют правила для известных ИИ-доменов и процессов claude.exe, codex.exe, antigravity.exe и языкового сервера. При ошибке фильтра проверьте его окно. Ctrl+C отключает фильтр. Статусы в Guard показывают доступность маршрутов внутри Guard. Переименованные программы, дочерние процессы с другими именами и назначения, скрытые собственным DNS или туннелем, могут получить другой маршрут. Состояние фильтра и работу с вашим VPN нужно проверить отдельно.

Крестик сворачивает Guard в область уведомлений. Для полного выхода используйте меню значка → Выход.
