# AI Exit Guard

AI Exit Guard — приложение для строки меню macOS. Оно направляет Claude, ChatGPT и Google Antigravity через выбранные прокси и показывает статус каждого сервиса.

**[Скачать для Mac](https://github.com/Waizor1/ai-exit-guard/releases/download/v1.14.0-beta/AI-Exit-Guard-1.14.0-beta.dmg)** · **[Скачать для Windows x64](https://github.com/Waizor1/ai-exit-guard/releases/download/v1.14.0-beta/AI-Exit-Guard-Windows-x64.zip)** · [Все выпуски](https://github.com/Waizor1/ai-exit-guard/releases)

Требуется macOS 13 или новее. Откройте DMG и запустите `AI Exit Guard.pkg`. Установщик запросит права администратора для системного помощника. Бета-сборка имеет локальную подпись ad hoc и не прошла нотарификацию Apple, поэтому Gatekeeper может остановить установку.

Подключите общий HTTP(S)- или SOCKS5-прокси. В списке выберите Claude, ChatGPT или Antigravity. Переключатель «Индивидуальный» позволяет назначить свой прокси выбранному сервису. «Общий» возвращает его на основной выход. Реквизиты хранятся в Связке ключей.

При красной оценке Guard закрывает туннели соответствующего сервиса. Каждый маршрут проверяется каждые две минуты. Доступ по нему действует до трёх минут с момента проверки. При сбое индивидуального прокси Guard ждёт восстановления этого маршрута.

В меню можно посмотреть соединения приложений и историю IP. Пароль прокси хранится в Связке ключей macOS. Для оценки адреса Guard обращается к IP123 и IPinfo.

### Google Antigravity

Подключите прокси и нажмите «Открыть Antigravity» в его карточке. Если приложение уже запущено обычным способом, завершите его через ⌘Q. Guard передаёт настройки локального прокси окну Antigravity и его языковому серверу. Для сетевых функций внутри этого запуска действует список разрешённых адресов. Запросы к посторонним сайтам через встроенный прокси могут получить отказ.

Guard проверяет страну на анонимной странице входа Google и репутацию IP, который на этом прокси наблюдает IP123. Страницы Google во внешнем браузере используют настройки браузера. Доступность аккаунта и региона Antigravity определяет Google. [Сетевые требования Google](https://antigravity.google/docs/enterprise)

## Системная защита

На Mac включите «Килл-свитч» в панели Guard. На Windows распакуйте ZIP, запустите **AI Exit Guard.exe**, заполните прокси и выходной IP, затем нажмите **Подключить** и **Включить защиту доменов**. Системное правило сохраняется после выхода из Guard. Программа, использующая системный DNS, получает локальный адрес для перечисленных доменов. Локальный вход пересылает HTTPS в Guard только при разрешённом маршруте. При закрытии Guard такие соединения обрываются. TLS остаётся между клиентом и сервисом. Управлять файлом hosts на Windows можно той же кнопкой.

Для дополнительных соединений откройте **Системные правила**. Guard использует отдельный подписанный ProxyBridge. Разрешите его сетевое расширение в macOS или драйвер в Windows. На Mac повторное нажатие переключает автозапуск фильтра. На Windows закрытие окна работающего фильтра отключает его правила. Доменные правила самого ProxyBridge зависят от доступности DNS-данных. Общие серверы входа Google принимаются внутри явного прокси, чтобы сохранить обычный вход в Google в других приложениях.

**Строгий запуск в T3 на Mac** включается через настройки Guard → **Защитить процессы T3**. Для новых процессов Codex, Claude и Antigravity, а также их дочерних команд разрешён сетевой выход только к локальному Guard. Команды загрузки пакетов, MCP и Git внутри них могут перестать работать. Для отключения очистите **Binary path** у нужного провайдера T3. Уже работающие процессы сохраняют прежнюю политику.

**Строгий режим Windows** устанавливает правила Windows Firewall для выбранного исполняемого файла. Укажите клиенту HTTP-прокси `127.0.0.1:39178`. Кнопка **Строгий режим для клиента** снимает правила при повторном выборе этого файла. После смены пути программы правило нужно установить для нового пути. Брандмауэр Windows должен быть включён. Отдельно запущенные дочерние исполняемые файлы на Windows имеют собственные правила.

Охват произвольного приложения ограничен известными назначениями. Скрытые домены, прямые IP, собственный DNS или вложенный VPN могут использовать другой маршрут. На macOS фильтр ProxyBridge умеет блокировать UDP по имени процесса, но не по домену для всех приложений. Зелёная оценка в Guard относится к проверенному выходу для конкретного сервиса.

## Локальная сборка

Понадобятся Mac, инструменты командной строки Xcode, Python 3 и Go 1.26.3 или совместимая более новая версия. Запустите сборку из корня проекта.

```sh
./build.sh
```

Скрипт собирает приложение и помощник для Apple Silicon и Intel. В папке `dist` появится образ `AI Exit Guard.dmg` с установщиком. Локальная сборка использует подпись ad hoc. Для подписанной и нотарифицированной сборки предусмотрен режим `./build.sh --release` с переменными `DEVELOPER_ID_APPLICATION`, `DEVELOPER_ID_INSTALLER` и `NOTARY_KEYCHAIN_PROFILE`.

## Проверка

```sh
go test -race ./...
python3 tests/check_red_relay.py
```

Вторая команда на macOS проверяет, что красный результат закрывает уже открытое соединение, новые подключения получают отказ, а полная зелёная проверка восстанавливает доступ. Тест использует локальный сервер.

Настройка прокси, разрешения macOS и значения статусов описаны в [инструкции пользователя](Инструкция.txt).
